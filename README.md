Приоритет 1 — ядро общего понимания (читать обязательно)
Глава 1, только раздел 1.7 (планирование, ~стр. 86–100): выбор сервера, что такое Intel-VT/AMD-V и аппаратная поддержка виртуализации, память, дисковая и сетевая подсистема, вопрос «мало мощных или много небольших серверов». Это аппаратный фундамент, общий для всех гипервизоров. Саму установку ESXi/vCenter/Auto Deploy — пропускай, это чисто VMware-специфика.
Глава 5 (ВМ), разделы 5.3–5.7: виртуальное оборудование (пункты Memory и CPUs), настройка «CPU/MMU Virtualization» (стр. 317 — там как раз объясняется аппаратная vs программная виртуализация MMU, в KVM это тоже важно), файлы ВМ (обязательно про VSWP — файл подкачки ВМ), снапшоты и их цена. Диски thin/thick у VMDK прямо аналогичны sparse/raw-дискам qcow2.
Глава 6 — целиком, это центральная глава книги и ровно твой список вопросов:
6.1 — limit/reservation/shares и пулы ресурсов: понятие оверкоммита и гарантий, переносится на cpu shares/cgroups в Proxmox;
6.2.1 CPU + NUMA (стр. 362–367) — механизмы планирования vCPU, NUMA-узлы;
6.2.2 Memory (стр. 367–385) — самое ценное: Memory Overcommitment, выделение по запросу, Transparent Page Sharing, balloon driver, memory compression, vmkernel swap — последовательность механизмов при нехватке памяти. Это та самая «лестница» спасения при исчерпании ОЗУ;
6.3 мониторинг — какие счётчики смотреть и пороговые значения, esxtop (аналог — top/perf у KVM);
vMotion (6.7) — как устроена живая миграция, концепция та же, что у KVM/QEMU. 
Приоритет 2 — второй круг
Глава 2 (сети): виртуальные коммутаторы, группы портов, режимы VLAN (EST/VST/VGT) — переносится почти один в один на Linux bridge/Open vSwitch в Proxmox; NIC teaming → bond.
Глава 3 (хранилища): обзор типов СХД (DAS/NFS/iSCSI/FC), multipathing — общая картина. Сами VMFS/VAAI/RDM — пробегай по диагонали, в KVM нет прямых аналогов.
